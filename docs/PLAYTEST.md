# HARVEST THE NIGHT - read me first

Thank you for playing this. It is a prototype, it is about an hour long, and
it is not finished. Below is what would be most useful from you.

## What it is

You farm by day. At night the same tiles are a tower defence and something
walks in from the dark to eat what you grew. You decide when the night starts
by pressing for it, so a day is as long as you want it to be.

Ten nights is the whole of it. If you get to the end, you have seen it.

## Play it once, without being told anything

**This is the most useful hour.** Start it, work out what to do, and stop when
you get stuck or bored. Do not ask me what a button does - if you cannot tell,
that is the finding, and the moment you ask, it stops being one.

If you get properly stuck, press **F1** and then carry on however you like.

## F1 leaves a note

Any time something is confusing, annoying, surprising or broken, press **F1**.
It writes a numbered marker into a log file with the time on it. It does not
ask you to type anything - it is one key, so you can press it mid-fight.

Afterwards, tell me what note 1, note 2 and note 3 were about. That is the
whole feedback format. Three sentences is plenty.

## What to try, if you have a second hour

- Get to night three.
- Build something other than a wall.
- Sell something at the stall.
- Lose on purpose and see what the game does about it.

## What to ignore

- **Placeholder art.** All of it is drawn from text maps and it shows.
- **Sound balance.** The mix is not done.
- **The tech tree past the first two rows.** Some of it is not wired up.
- **Anything after night ten.** It stops.
- **The orange box at the start of each run.** That is this build, not
  the game. It goes away after a few seconds.

## What to report, in order of how much it helps

1. **Where you stopped playing and why.** The most valuable sentence there is.
2. **Anything you expected to be able to do and could not.**
3. **Anything you did by accident.**
4. Crashes. The game writes a folder for those and tells you where it is.
5. Typos, spacing, a label in the wrong place.

## The log

Everything above is written to a file on your own machine:

    %APPDATA%\Godot\app_userdata\HARVEST THE NIGHT\playtest\

It is plain text. It is what you did and how long it took - no name, no
addresses, nothing from outside the game's own folder. **Nothing is sent
anywhere**: the game has no network code in it at all. Open it, read it, and
send it or do not, as you like.

If a crash happens the game writes a separate folder and shows you where the
next time you start it. Same rules: plain text, local, yours.
