# Walk right: one-direction approval candidate

Walk down was explicitly approved: "lindo, perfeito". The user's next request
requires one further direction at a time and explicit review after each one.
This task produces RIGHT only, including a standing directional master.

Source identity: `../character-r1`, as approved by the user. Workflow follows
the external sprite_generator rotation-first, anatomical leg-color tracking,
eight-phase gait, then material-restoration method documented in walk-down.
The right-facing guide adapts the concepts in ranger_right_leg_guide.py; it is
an anatomy schematic only, never the final artwork. Near/anatomical right leg
is red, far/anatomical left leg cyan. Color identity stays attached to the hip
through contact, toe-off, passing and reaching, with near-leg occlusion fixed.

Generation uses built-in ImageGen. Exact prompts live beside this document;
masters are in assets/art_source/player-fhd/pilots/2026-10-04/walk-right.
The standing master is inspected internally as a prerequisite for this single
movement; the finished idle-plus-walk is the user's approval checkpoint.

`python implementation/fhd-player/pilots/2026-10-04/walk-right/export_preview.py`
cuts the 4x2 atlas with one common movement scale, hard alpha and nearest
sampling. Output is eight 80x80 RGBA frames, a horizontal transparent strip,
normal 10fps idle/walk/detail GIF, slow diagnostic GIF and individual-frame HTML.
Standing height is 64 native pixels, proposed integer 2x display (128px at FHD),
matching the approved down pilot. Enlarged detail is a separate inspection view.

This is a review candidate, not runtime integration. No other directions,
activities, game changes or tests of actual game rendering are included.
